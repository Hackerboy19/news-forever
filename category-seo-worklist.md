# Category SEO worklist

Audited live on newsforever.in: **78 categories, 78 with weak metadata**, 70 of which have published articles.

The cause is a UI behaviour, not bad data entry: the Add Category form pre-fills
Meta Title with the category name. Anything saved without opening the
**Search / SEO** tab ends up titled with just its own name and a matching
one-word description.

Fix in **Admin → Category → Edit → Search / SEO tab**. Aim for a description of
120–165 characters.

## Also worth a look: duplicate category names

These names each exist more than once — and, importantly, **each duplicate set
shares one web address**. `/category/Astrology` is a single URL backed by three
separate category rows (#40, #48, #61).

The server resolves a slug by taking the first row that matches it, so only one
of each set is reachable. The others' articles are not shown under that URL at
all. Merging each set into one category — move the articles across, then delete
the spares — would recover them.
